# BallUp Assets

Eine Quelle für alle Marken-Assets. Die Mobile-App, Merch, Social und der Asset-Sammler nehmen ihre Dateien von hier.

```
assets/
  maskottchen/
    aktuell/   aktueller Stil (v4 Flash-Cartoon), freigestellte PNGs + SVG; wird in Git eingecheckt
    archiv/    alte Versionen v1–v3, Illustrator-Trace, Stilproben; nur lokal, steht in .gitignore
```

Dateinamen: `<Kategorie>_<Figur>_<name>.png`, z. B. `Frisur_Junge_gel-spikes.png`.
Neue Assets kommen nach `maskottchen/aktuell/`. Alte Stände kommen nach `archiv/`, statt überschrieben zu werden.
Entscheidungen dazu stehen in Notion (Design → Decisions, DEC-013).
