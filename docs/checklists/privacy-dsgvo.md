# Datenschutz / DSGVO

- [ ] Verzeichnis der Verarbeitungstätigkeiten: welche Daten, Zweck, Rechtsgrundlage, Speicherdauer
- [ ] Datenschutzerklärung deckt ab: Account, Standort, Fotos/Kamera, Chat, Push, Analytics, Crash-Reports
- [ ] Alle Dienstleister in der EU bzw. mit AV-Vertrag (Hetzner, Object Storage, CDN, E-Mail)
- [ ] Standort nur „während der Nutzung“, präzise nur wo nötig; Courts statt Live-Position teilen
- [ ] Einwilligung vor optionalem Tracking/Analytics, jederzeit widerrufbar
- [ ] Recht auf Auskunft: Datenexport pro User möglich
- [ ] Recht auf Löschung: Account-Löschung in der App, inkl. Uploads und Chat-Nachrichten (oder Anonymisierung)
- [ ] Mindestalter festgelegt und im Onboarding abgefragt; Regeln für Minderjährige geprüft
- [ ] Logs und Traces ohne personenbezogene Daten im Klartext (keine Tokens, E-Mails, exakten Standorte)
- [ ] Aufbewahrungsfristen technisch umgesetzt (Retention in Loki/Tempo/Backups)
- [ ] Meldeprozess für Datenpannen (72 Stunden) im Incident-Runbook beschrieben
