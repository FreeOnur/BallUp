# Design-System

Gepflegt vom **designer**-Agent. Jede Regel stammt von Onur (bzw. den Gründern) und nennt die Quelle. Fehlt eine Regel, wird gefragt, nicht erfunden. Die ausführlichen Entscheidungen stehen in Notion unter Design → Decisions.
